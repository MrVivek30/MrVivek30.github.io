Enterprise FinTech & High-Scale Sync Engine

TrackoField — Midland DB Syncing & Large-Scale Data Pipeline

Architected and optimized an end-to-end data synchronization pipeline between an enterprise financial client's (Midland Microfin) Microsoft SQL Server and TrackoField's MongoDB, processing 5–10 Lakh records with strict memory and consistency guarantees.

  • 97% Sync Runtime Optimization: Slashed member DPD/OD sync runtime from 2+ hours down to 2.8 minutes (167.9 seconds) for 428,737 rows fetched and 242,158 members updated using streaming JDBC (fetchSize=1000) and Spring Data mongoTemplate.bulkOps(UNORDERED).
  • MongoDB Compound Index Alignment: Eliminated full collection scans (COLLSCAN) across millions of documents by engineering compound indexes ({ cmpId: 1, mbrCde: 1 } and { cmpId: 1, asgTo: 1 }), enabling sub-second multi-tenant lookups.
  • Eliminated the "1h 16m" Edge Case Black Hole: Replaced static calendar-day filters with a rolling 24-hour lookback window, ensuring new users created between 10:44 PM and 12:00 AM midnight are never dropped between daily scheduler runs.
  • JVM Heap & Memory Safety: Prevented OOM errors and stabilized JVM heap allocation during high-volume syncs by combining JDBC streaming with explicit batch collection lifecycle cleanup.
  • Hierarchical Workflows & Schedulers: Orchestrated dependent monthly master-syncs (Centers, Groups, Members) and daily delta-syncs handling closed-loan deactivations, delinquency priority updates, and automated collection task generation.
