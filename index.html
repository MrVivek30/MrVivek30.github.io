02
Enterprise FinTech · High-Scale Data Pipeline

TrackoField — Midland DB Syncing Pipeline

Architected and optimized an end-to-end data pipeline syncing 5–10 Lakh records between an enterprise financial client's (Midland Microfin) MS SQL Server and TrackoField's MongoDB with zero memory leaks.

  • 97% Sync Runtime Speedup: Slashed sync execution from 2+ hours down to 2.8 minutes for 428,737 rows fetched and 242,158 members updated using streaming JDBC (fetchSize=1000) and Spring Data mongoTemplate.bulkOps(UNORDERED).
  • Compound Index Optimization: Replaced full collection scans (COLLSCAN) across millions of documents with compound indexes ({ cmpId: 1, mbrCde: 1 } and { cmpId: 1, asgTo: 1 }), enabling sub-second multi-tenant lookups.
  • Eliminated 1h 16m Edge Case: Replaced static calendar-day filters with a rolling 24-hour lookback window, ensuring users created between 10:44 PM and midnight are never dropped between daily scheduler runs.
  • JVM Heap Stabilization: Prevented Out-Of-Memory (OOM) errors during peak syncs by streaming cursor buffers directly into batched MongoDB writes.

Multi-Stage Hierarchical Sync: Automated monthly master dependencies (Centers, Groups, Members) and daily delta syncs handling closed-loan deactivations, delinquency priority recalculations, and automated collection task generation.
